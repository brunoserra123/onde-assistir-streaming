# 🎬 Onde Assistir? — Guia de Filmes e Séries no Streaming (Brasil)

Plataforma web moderna para pesquisar qualquer **filme ou série**, visualizar as **capas oficiais**, notas IMDb, sinopse e descobrir instantaneamente **em qual plataforma de streaming está disponível no Brasil** (Netflix, Prime Video, Disney+, Max, Globoplay, Apple TV+, Paramount+, Crunchyroll, etc.), com links diretos para assistir.

## ✨ Funcionalidades
- 🔍 **Busca Instantânea**: Digite o nome de qualquer filme ou série (em português ou título original).
- 🖼️ **Capas e Detalhes em Alta Definição**: Pôster oficial, imagem de fundo, nota IMDb, ano, duração, classificação indicativa e sinopse em português.
- 📺 **Onde Assistir em Tempo Real (Brasil)**:
  - 🟢 **Assinatura (Stream)** — Incluso nos catálogos (Netflix, Prime Video, Disney+, Max, Globoplay, etc.)
  - 🆓 **Grátis** — Plataformas gratuitas
  - 🟡 **Alugar** — Com valores em Reais (`R$`)
  - 🔵 **Comprar** — Com valores em Reais (`R$`)
- 🎯 **Filtros Rápidos**: Filtre por Filmes, Séries ou por sua plataforma de streaming favorita.

## 🚀 Como Usar
- **No Computador / Celular**: Basta abrir o arquivo `index.html` em qualquer navegador.
- **No GitHub Pages**: Hospede gratuitamente subindo este repositório para o GitHub e ativando o **GitHub Pages** na aba *Settings > Pages*.
